# ♟️ Chess App

Um aplicativo de xadrez desenvolvido com o objetivo de proporcionar partidas entre jogadores.

## 🚀 Funcionalidades (em desenvolvimento)

- [x] Interface gráfica para o tabuleiro de xadrez  
- [x] Movimentação legal de peças  
- [x] Suporte para partidas entre dois jogadores  
- [x] Validação de regras de xadrez

## 📦 Instalação

```bash

# Acesse a pasta do projeto
cd Chess-App

# Instale as dependências
npm install

# Inicie o projeto (ajuste conforme seu script)
