# ♟️ Chess App

Um aplicativo de xadrez desenvolvido com o objetivo de proporcionar partidas entre jogadores.

## 🚀 Funcionalidades (em desenvolvimento)

- [ ] Interface gráfica para o tabuleiro de xadrez  
- [ ] Movimentação legal de peças  
- [ ] Suporte para partidas entre dois jogadores  
- [ ] Validação de regras de xadrez  

## 🛠️ Tecnologias utilizadas

- React.js
- Node.js
- Socket.io

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/iagoxz/Chess-App

# Acesse a pasta do projeto
cd Chess-App

# Instale as dependências
npm install

# Inicie o projeto (ajuste conforme seu script)
npm start
